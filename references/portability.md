# 环境与移植

在新机器开始任务、宿主切换或能力失败时读取。只检查本轮相关工具与获准目标；先确认已有能力，缺项时说明所需能力及替代路线，不自动安装整套软件。

## Agent 负责什么

本包提供 Markdown 指令、参考规则、最小 Python 标准库状态辅助器及测试；没有模型服务、自动执行引擎、Word 插件或实验虚拟机。状态辅助器记录版本与守门条件，不调用外部工具。宿主需能读取本地文件并按相对路径继续读取参考文档。运行真实实验、截图、编辑或渲染均需宿主提供相应工具和权限。安装技能只让 Agent 能发现说明，不会增加这些能力。

Codex 与 Claude Code 可通过各自技能目录发现根目录的 `SKILL.md`。没有技能加载器的 Agent 可以由用户明确指向该文件，再按需读取同目录参考文件。把包复制到另一台电脑不应携带个人报告、登录状态或绝对路径。DeepSeek harness 的安装与验证状态以 [README](../README.md) 为准；不能仅凭“支持 Markdown”声称完成执行兼容。

DeepSeek harness 已核对 [官方文件系统技能说明](https://github.com/deepseek-ai/deepseek-harness/blob/687f282e8625c6b8d11ff58211a90524be2e4317/packages/skill/skill-filesystem/README.zh.md)：项目 `.dsh/skills`、`.agents/skills` 是默认扫描根，技能须为根直属 `<name>/SKILL.md`，具有 `name` 和 `description`。启用 `skill`、`skill-filesystem` 提供方及 `dsh-tool-skill` 消费工具；配置 `includeDefaultRoots=false` 会关闭默认根，届时需按该环境配置显式接入。源码支持目录结构不代表本技能已在该宿主完成运行验证。

## 按实际任务选择工具

| 需要完成的动作 | 可用路线 | 实际依赖与边界 |
| --- | --- | --- |
| 读要求、审核文字 | 宿主文件读取工具 | 不需要 Python、Word 或网络；扫描 PDF、图片内容仍需要 OCR/视觉能力 |
| 编辑普通 DOCX 副本 | 已有 Word、LibreOffice，或 Python + `python-docx` | Python 不是 Word 渲染器；`python-docx` 不能保证复杂域、公式、浮动对象和转换完整性，必须检查往返保存 |
| 高保真核验 Word 模板 | 目标版本的 Microsoft Word | Windows 自动化可用 PowerShell COM；若用 Python COM 才需 `pywin32`。COM 仅适用于支持它的 Windows 桌面环境；macOS/Linux 不提供同一路线 |
| 导出验收 PDF | Word 导出，或 LibreOffice 的 `soffice --headless --convert-to pdf` | 两者均需实际安装且能够启动；输出到独立目录并核对文件存在及页数。LibreOffice 预览不能称为 Word 实测 |
| 逐页视觉复核 | 宿主 PDF 查看器；或 Poppler `pdftoppm` / Python + PyMuPDF | PDF 文本抽取不能代替看页面；需能实际查看页面图像。PDF 是验收中间文件，不自动成为课程交付物 |
| 真实实验与截图 | 课程指定 VM/容器/工具、宿主截图工具 | 包不提供课程软件和账户；只有 shell 输出时不能伪造编辑器或桌面截图 |

字体依赖从实际模板读取。模板指定的中西文字体需目标机器可用，不能把中文宋体直接用于英文；Times New Roman 仅是常见英文模板提示。缺字体时先报告缺项，按授权补装合法字体或说明替代方案。不要把商业字体打包公开。替代字体可能改变换行、分页和公式显示。

## 最小预检与降级

1. 确认输入可读、输出目录可写，保护原模板；记录实际目标应用与字体。处理带空格和中文路径时传递完整路径，避免字符串拼接命令。
2. 仅验证任务所需路线。可用终端时读取 `python --version`、`soffice --version` 或命令发现结果作为线索；这些结果不代表文档可正确渲染。已有应用或连接器可直接检查能力，无需为了预检安装 Python。
3. 在实际候选副本验证编辑、保存、重开、渲染，核对实际存在的公式、分节、表格和保护区；不为技术预检设置额外小样审批。局部修改检查受影响部分，用户明确要小样时再提供。
4. 仅缺实验环境：可继续审材料与允许的文档修订，实验项标“未执行/缺证据”。仅缺渲染器：保留可编辑候选和检查记录，标“视觉未验收”。仅能写 Markdown：先提供明确标注的草稿，不声称已交付 Word 或自动改变要求格式。
5. 工具报错时先核对输入、进程占用、权限、字体及格式支持；每次重试应有新依据。无法完成的分支说明具体缺项，继续独立工作；不以弱化验收换取“通过”。

本文件描述可选路线，不表示本仓库已在所有操作系统、Office 版本或 Agent 上完成端到端测试。实际验证记录见 [验证说明](../docs/validation.md)。

## 经验层的启停与宿主适配

核心是 Python 3.9+ 标准库 CLI，没有模型调用、向量数据库、常驻服务或多设备同步。Codex、Claude Code、Cursor、通用 Agent 和 DeepSeek harness 共用显式 begin、collect、checkpoint/end；不假设各家 hooks.json 同义。Cursor 为 2.1 新增说明目标，未做客户端端到端运行认证。宿主原生 ID 不可得时，启动器生成并保留 token，恢复显式复用。普通启动、压缩、回复/工具/子 Agent 结束均不触发经验人审。

| 情况 | 路线 |
| --- | --- |
| 关闭或空库、从未采用 | 直接按原五段流程；关闭不读/建根，空库无候选便不凑审核 |
| 项目外沙箱不允许私有根 | 用已有授权/宿主权限入口；无依赖时记录 unavailable 并降级，不搬到技能/任务/课程提交目录 |
| 根故障且从未采用 | 记最小恢复指针，继续原流程，后续补收有依据的事件 |
| 已采用后库故障或关闭 | 保留依赖和历史；恢复根核查，或当前材料局部复核并显式 detach，之后重新独审 |
| 无 Python | 原流程可读写继续，手工留最小状态；本轮经验增强关闭，不能声称执行过 CLI 门控。已有依赖先按协议解除 |
| 无 hooks/无插件 | 主编排者在实际纠正及阶段检查点调用 host_adapter，不依赖 SessionEnd，不安装未知工具 |
| Claude Mem 可选来源 | 只导入已授权本地导出，先确认没有默认自动注入旁路；否则禁用此路线并用干净执行上下文 |
| 云端/远程宿主 | 本地私有根不会自动可见或同步；不上传资料补洞，不把连接本地根当既有权限 |

Claude Mem 适配的固定版本、导出格式、默认注入风险及验证层级见 [宿主适配](host-adapters.md)。停用本适配器不停止外部插件的全局注入；无法确认干净上下文时，只能报告限制或换到已确认不含该注入的上下文，不能靠提示模型忽略。
