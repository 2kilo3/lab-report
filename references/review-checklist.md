# 独立审查与修订复核

## 审查上下文与分工

独立 Agent 必须读取：原始任务/模板/量规及必要范例、用户确认的意图 MD、当前成稿、必要原始证据及当前渲染。不给作者总结替代原材料，不预灌“已经通过”的结论。制作方可提供修改范围和定位，审查者自行核对。

优先原生 subagent；否则用已有可用 Agent CLI/API 新会话或独立上下文进程。独立是推理上下文分离，不要求不同模型；新开 shell 但继续同一会话不算。调用仍受资料传输、凭据、工具与执行权限限制，不自动安装或创建密钥。确无路线时报告具体能力缺口，不能把自检命名为独审。

按实际任务判断适用项，不凭清单新增章节或实验。意见包含位置、问题、原始依据、影响和最小修正。结果区分通过、已证实问题、缺证据、未验证、不适用。制作方核实意见后修，证据不支持时说明理由；真实未解矛盾或需变更确认意图才问用户。修改后由独立审查者复核原问题与关联影响，绑定当前版本，不把“已修改”当“已通过”。

## 内容与证据

- 意图清单覆盖原材料每个任务/子要求，来源真实可定位；建议明确区分推导。评分有最高档则照做，无量规不编分数。额外组成遵统一确认的意图，不另加审批。
- 结构和文体符合本次模板与意图；普通实验报告截图为主、必要短文，论文不强套此方式。范例数据/结论没有混成本次事实。
- 每项必需结论有对应证据；实现、执行、观察、推断分开。关键参数、单位、计算和比较条件正确；没有由真截图跳到无依据解释。
- 原图与对象/轮次/实际代码配置对应；旧状态或累计值不冒充本轮。负结果有采集有效性和必要对照；没有降低标准或隐去失败求通过。
- 真实截图动作自然：代码打开实际文件定位，下载打开实际目录/文件；正常终端操作允许，后台工具允许。文件存在、可打开、字节一致不混为一谈。
- 查看实际嵌入图片，不只看外部素材。普通报告独立截图各有图号/具体图名，真拼图可共用；论文组合图按模板。图序、引用及来源一致，关键内容可读，无伪造/截掉条件/错配。
- 正文必要、直接、连贯，执行细节不无故重复抄图；必要协议字段、算法、流程或论文方法论述未删。按 [写作规则](academic-writing.md) 复核，不机械删禁词、编亲历、补统计显著性或承诺 AI 检测结果。

## 样式与文件

- 原始模板保持不变；输出副本的固定封面/评分区、嵌套表格、分节等保护区没有被共享样式或转换破坏。
- 标题、正文、图题沿同类模板；标题不误继承正文首行缩进，不擅造粗体样式。中西文字体分别按模板核实，不机械一律宋体或 Times New Roman；公式/专用符号及截图不乱改。
- 表格按模板；未规定用白底黑字黑色实际边框，原生可编辑。检查表头、条件样式、合并格及跨页，不用辅助网格或图片化替代。
- 图片和图题邻接、编号统一，模板未规定时图下居中、不加粗、尽量同页；图宽随内容可读性，不拉伸或压到难读，不用无关内容填空。
- 由最终候选保存、重开并生成当前预览。修改后重验受影响页及关联分页；旧 PDF 不证明新 Word。代用软件渲染不声称 Word 实测，结构检查不等于视觉通过。
- 作者/创建者/最后修改者为本次核实实际作者，最终格式回读；软件生成器与人物字段分开，不能猜身份或篡改批注历史。

## 门槛与交付

- 未获得当前意图实际确认不能实施，已确认且未变不重复问；不强制小样或第二份补齐计划。确认不扩大权限。
- 意图、材料、证据、成稿变化后，旧审核必须失效或重新核实影响，不能凭旧“通过”交付新版。局部格式问题不重做实验，证据问题返回对应实验；无关已有效成果保留。
- 审查任务不擅改正文；禁止补测时不重跑。审查完成可以指出文档不合格，不混淆任务完成和文档通过。
- 默认 Word 加一份简短审核 MD，按内容/样式归类，简述已查范围、关键问题及未验证项，不倾倒内部日志。提供实际报告供人看，用户未回复不代表人审通过。
- 交付物与检查版本一致，必要附件完整，不夹私密资料/缓存/旧稿；上传成功与制作完成分别核实。

状态脚本只能验证记录结构与文件版本。审查者 ID、会话引用、勾选项都不证明独立性或审查质量，执行者仍要核实真正独立的审查及证据。未通过的关键项不能凭脚本状态抹去。
