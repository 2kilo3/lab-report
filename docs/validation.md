# 验证说明

本技能是 Markdown 工作流。版本 1.5 的检查看的是指令、链接、范围与可移植性；它不包含可重复运行课程实验的测试环境。

## 已做的检查

- 阅读原始入口、全部 6 份参考文档和 29 个原有行为场景，保留制作、审查、修改、真实取证与最终文档复核的职责。
- 将 Humanizer-zh 的语言编辑思路适配到既有写作模块；逐项核对对数值、技术术语、失败、局限和模板的保护。
- 对照 DeepSeek harness 官方固定版本文档核实目录、入口字段和加载前提；没有把源码支持目录当作宿主运行测试。独立交叉审查发现测试设计未显式继承当前授权优先规则，已补充共同前提，防止测试反向要求重复确认。
- 原始包以 SkillSpector 2.12.0 的 `--no-llm` 模式扫描：8/100，LOW；唯一 AS3 MEDIUM 命中的是公开 GitHub 来源链接，不是对本机已安装技能的枚举。静态扫描的来源引用解析为 partial，不能写成全量安全证明。
- 逐项人工推演下列构造输入；这是文档行为检查，没有启动独立客户端、真实 VM 或 Office 应用。

| 构造输入 | 本轮推演得到的输出/处理 | 判断 |
| --- | --- | --- |

## 仍需真实任务验证

`tests/scenarios.md` 的 33 项是后续行为测试设计。它们没有全部由独立 Agent 执行，也不构成“33 项已通过”。当前未执行真实课程全流程、全平台安装、DeepSeek harness 端到端运行、Word/LibreOffice 版本矩阵、实际复杂模板往返保存或字体完整性验收。

在新机器上先按 [环境与移植](../references/portability.md) 验证本次所需能力，并以真实完整小样检验实际模板。成功加载技能、静态扫描通过与报告合格是三个不同结论。
